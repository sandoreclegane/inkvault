# First-run sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `inkvault sync` in a terminal greet the user, show search progress, report truthfully what was kept, and open the Atlas; leave every non-terminal path byte-for-byte unchanged.

**Architecture:** A new `term.py` owns all terminal decisions (whether to use new output, whether to decorate, encoding-safe rendering, Windows VT, a progress reporter). Sync steps return structured counts instead of only printing; a small `summary.py` reads totals and before/after conversation identities from the vault and search index. `cmd_sync` wires them together and launches the Atlas after the lock is released.

**Tech Stack:** Python 3.10–3.13 stdlib (`ctypes.wintypes`, `sqlite3`, `threading`), existing model2vec/numpy; pytest.

**Spec:** `docs/superpowers/specs/2026-10-16-first-run-design.md` (revision 3). Read it first; this plan does not repeat its rationale.

## Global Constraints

- No new dependencies (no `rich`, no `colorama`).
- Non-TTY `inkvault sync`, and all of `nightly`, `rescue`, `index`, `serve`: output unchanged byte for byte.
- Plain and non-TTY output never contains ESC (`\x1b`) or `\r`.
- A cosmetic failure (encoding, console mode, launch) never raises and never changes the exit code.
- Every summary number names its unit and comes from committed vault/search data; nothing is subtracted.
- Auto-open only: stdin TTY **and** stdout TTY **and** full success (exit 0) **and** no `--no-open`; after the sync lock is released.
- Golden MCP test (`tests/test_mcp_golden.py`) unchanged and passing.
- Run tests with `uv run pytest -q`; lint with `uvx ruff check --select F src tests`.

## Review Focus

1. A user on Windows PowerShell 5.1 under `uvx` (cp1252 stdout): the whole run, including errors, prints in ASCII without raising. Test in Task 1 (`test_full_message_set_cp1252`).
2. The user presses Ctrl+C during "Building search": the spinner stops, the cursor line is finished, no thread writes after the traceback/exit. Test in Task 2 (`test_reporter_stops_on_keyboard_interrupt`).
3. A first-ever run with no previous search index: every conversation counts as "with new messages", no crash on the missing `search.db`. Test in Task 4 (`test_first_run_without_search_db`).
4. A second `sync` minutes later with nothing new: "0 with new messages", and the Atlas still opens (an already-running helper is reused). Tests in Task 4 (`test_rebuild_unchanged_reports_zero_new`) and Task 5 (`test_auto_open_when_nothing_new`).
5. The search build itself fails (e.g. model download error offline): summary shows Search with `!` and the reason, exit 1, no auto-open, sessions/visits still reported. Test in Task 5 (`test_search_failure_reported`).

### Task 5: First-run `sync`

**Files:**
- Modify: `src/inkvault/cli.py` (`cmd_sync`, `ask_browsers`, `sync` subparser), `src/inkvault/browsers.py` (`ask`, `ask_about_new` — presentation only, via an optional `term` argument)
- Test: `tests/test_first_run.py`

**Interfaces:**
- Consumes: Tasks 1–4.
- Produces: `inkvault sync --no-open`; `cli.FIRST_RUN_MESSAGES: tuple[str, ...]` (every fixed string the new output can emit, for Task 1's encoding test).

Flow in `cmd_sync(args)` when `Term.detect().new_output`:
1. Hello line (spec wording) before `ask_browsers`.
2. Browser question with styled heading `Which browser profiles are yours?`; parsing unchanged.
3. Inside the lock: `before = summary.conversation_ids()` after `forget.apply_pending()`; run sessions and browsers; build search if recovering or sessions in (`ok`, `partial`) or web in (`ok`, `partial`) — **session partial is now build-eligible**; `after = summary.conversation_ids()`; compute `session_lines`, `visit_total`; keep them for printing.
4. After the lock: print `Saving…` block, one line per found source (`✓` or `!` + reason), browser line (`visits`, `+N new`, profile count), Search line (`up to date` or `!` + reason).
5. Exit 0 only if sessions `ok`/`none`, web `ok`/`nothing`, and search built. If exit 0 and `term.interactive` and not `args.no_open`: print `Your vault is ready. Opening the Memory Atlas…` then `atlasserve.start_detached()`; on `OSError` print `Couldn't open the Atlas; open it with: inkvault dashboard` (exit stays 0). Otherwise print `Open it with: inkvault dashboard`.
6. Last line when opened: `Next time: inkvault sync · skip the browser: --no-open`.

When `new_output` is False, `cmd_sync` takes today's code path unchanged.
